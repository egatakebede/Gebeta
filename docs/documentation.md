# Gebeta Documentation

## Overview
Gebeta is a restaurant food ordering and delivery platform built with HTML, CSS, JavaScript, PHP, and MySQL.

## Features
- Customer browsing and restaurant discovery
- Login/register modals
- Cart and checkout flow
- Order tracking
- Restaurant owner dashboard and menu management
- Admin pages for restaurants, users, orders, and reports
- AJAX features for live search, cart updates, and email validation

## File structure
- `index.php` – landing page with authentication modals
- `customer/` – customer-facing pages
- `restaurant/` – restaurant owner pages
- `admin/` – admin panel pages
- `api/` – AJAX endpoints
- `includes/` – shared configuration, database, and helper code
- `assets/` – CSS and JavaScript
- `docs/` – setup and documentation
- `gebeta.sql` – database schema and sample data
